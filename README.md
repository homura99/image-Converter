# 画像形式変換ツール

## 起動方法
1. `index.html` を Chrome / Edge / Firefox などのブラウザで開きます。
2. 画像をドラッグ＆ドロップするか、「画像を選択」を押します。BMPを含む画像ファイルを入力できます（読み込みはブラウザの対応状況に依存します）。
3. 出力形式・画質・必要に応じて幅と高さを設定します。
4. 「一括変換」を押し、各画像の「保存」または「変換済みをZIPで保存」を使います。

## 技術
- HTML / CSS / JavaScript
- Canvas API（画像の描画・変換）
- heic2any 0.0.4（HEIC/HEIFのブラウザ内デコード、CDN経由）
- ICOヘッダー生成（内蔵）
- BMP（24bit非圧縮）エンコード（内蔵）
- JSZip 3.10.1（ZIPダウンロード、CDN経由）

## プライバシー
画像本体はブラウザ内で処理し、変換サービスへアップロードしません。ZIP機能とHEIC/HEIFデコードのためにJSZipとheic2anyをCDNから読み込みます。完全オフラインで使いたい場合は、両ライブラリをローカルに保存し、scriptタグをそれぞれのファイルに変更してください。

## 注意点
- JPGは透明部分を保持できないため、既定では白背景に合成します。
- BMPは24bit非圧縮形式で出力し、透明部分は既定で白背景に合成します。
- GIFアニメーションは静止画として変換されます。
- HEIC/HEIFはheic2anyでPNGにデコードしてから変換します。そのためCDNへの接続が必要です。
- AVIF等はブラウザの対応状況によって読み込み可否が変わります。
- ICOは最大256×256pxの単一PNG画像を格納する簡易ICO形式です。古いソフトとの互換性要件がある場合は専用ライブラリでの検証を推奨します。
